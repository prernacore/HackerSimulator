# NEXUS — Cyber Terminal Simulator

A browser-based cybersecurity training simulator built using HTML, CSS and JavaScript.

## Features

- Interactive terminal commands
- Simulated network scanning
- Mission progression and XP system
- Dynamic system monitoring dashboard
- Responsive cyber-themed interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Type `help` in the terminal to explore commands.

## Purpose

This project is created for learning frontend development, JavaScript logic, and cybersecurity concepts through a fictional simulation.

All network activity is simulated.
